Active Directory Migration Lab

Windows Server 2008 R2 to Windows Server 2022 | Active Directory Domain Services | PowerShell | Infrastructure Modernisation

Project Overview

Designed and implemented an Active Directory migration laboratory to modernise a legacy Windows Server 2008 R2 infrastructure using Windows Server 2022.

The project involved creating a new Active Directory forest, migrating organisational units, users, security groups, group memberships and computer accounts, and reviewing legacy Group Policy Objects.

The migration was performed in an isolated VirtualBox environment while preserving the original Active Directory domain and its configuration.

Migration Implementation

Active Directory Forest Deployment

Deployed Windows Server 2022 and configured Active Directory Domain Services, DNS and the new ad.castillux.com forest.

Organisational Unit Migration

Recreated 20 organisational units while preserving the hierarchical structure of the legacy domain.

User and Security Group Migration

Migrated 129 user accounts, 21 security groups and 153 direct user-to-group memberships. Imported accounts were initially disabled for safety.

Computer Account Migration

Exported an inventory of 223 legacy computer objects and recreated 222 disabled computer accounts in the new domain, preserving their organisational unit locations.

The original domain controller was excluded. Physical computers were not automatically joined to the new domain.

Group Policy Migration

Backed up 38 legacy Group Policy Objects and imported 10 selected policies under LAB-prefixed names. Legacy references and security settings were reviewed. Imported policies remained unlinked to prevent unintended configuration changes.

Troubleshooting

PowerShell Computer Import Errors

The initial bulk import encountered 222 errors caused by the computer existence-check logic.

Replaced the failing identity lookup with a comparison against existing computer names, successfully importing the remaining objects.

Legacy Group Policy References

Identified outdated domain references, printer connections, network drive mappings and firewall exceptions. Reviewed the imported policies without applying them to production systems.

Validation & Results

Active Directory Health

Verified domain controller advertising, directory services and DNS using DCDIAG. Confirmed that SYSVOL and NETLOGON shares were available.
